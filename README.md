# Accidentes de Tránsito con MongoDB

## Descripción del proyecto

Este proyecto tiene como objetivo almacenar y analizar información de vehículos involucrados en accidentes de tránsito utilizando MongoDB, una base de datos NoSQL orientada a documentos. Para ello, se emplea el conjunto de datos contenido en el archivo VEHICULOS_INVOLUCRADOS_EN_UN_ACCIDENTE_DE_TRANSITO_LEY_2251-2022 (1), el cual contiene información relacionada con vehículos involucrados en siniestros viales. 【1-755331】

## Caso de uso

Las bases de datos NoSQL como MongoDB permiten manejar grandes volúmenes de información de forma flexible y escalable. En este proyecto, MongoDB se utiliza para almacenar registros de accidentes de tránsito y realizar consultas que facilitan el análisis de los datos.

## Base de datos

- Base de datos: `accidentes_transito_db`
- Colección principal: `vehiculos_involucrados`

## Objetivos

- Importar datos desde un archivo CSV a MongoDB.
- Implementar operaciones CRUD (Crear, Consultar, Actualizar y Eliminar).
- Realizar consultas con filtros y operadores.
- Generar estadísticas mediante consultas de agregación.
- Analizar información relacionada con los accidentes de tránsito.
